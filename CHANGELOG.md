# Changelog

## 0.4.0-alpha.1 — 2026-11-02

- First public GitHub alpha. Adds the Codex embedded panel/runtime 0.4.0 alongside
  the preserved DSH 0.2.0 package at the repository root.
- Photo/measurement briefs, parametric SCAD guidance, hash-bound STL checks,
  actual-mesh previews, five-file successful revisions and explicit ZIP export.
- Adds a repo marketplace, explicit external-runtime setup, portable launch
  wrapper, release notes and known limitations.
- Ordinary ChatGPT iPhone use is a required next feature, not a shipped claim.
  No OpenAI directory approval or hosted CAD backend is included.
- Existing DSH root installation and v0.2.0 tag remain available. The two adapters
  have distinct versions and capabilities; this release does not silently upgrade
  an installed DSH or Codex plugin.

Software remains MIT; the bundled font and JS licenses are retained separately.
