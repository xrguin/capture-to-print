# Five-file revisions — 0.4.0

New successful runs retain exactly:

- `design.scad`: editable source.
- `design-contract.json`: required dimensions and tolerances.
- `part.stl`: exported mesh.
- `revision.json`: check results, source/mesh/preview hashes, build versions, successful-log summaries, resource references and pending review state.
- `preview.png`: face/back/edge/oblique views in one 1440×2000 PNG. The panel crops each view in memory.

No ZIP is generated by build. Ask for a full bundle, click **Create full ZIP**, or run `python scripts/capture_to_print.py export RUN --output EXPORTS/full.zip`. Exports do not change the revision and do not rebuild CAD. They include the five files, six pinned rebuild resources, instructions and a manifest (13 ZIP entries).

Rebuild resources are stored once per content hash in `.resources/` alongside the revisions. They must remain available for later export. Briefs/photos and project bookkeeping remain outside revisions. Failed builds retain diagnostic files separately. Standalone low-level check/render commands retain their explicit-output behavior. Older runs remain readable and are never migrated or deleted.
